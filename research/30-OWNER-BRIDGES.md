# 30 — Owner Bridges

Host continuity is useful precisely because it can persist references across owner boundaries without absorbing the owners.

| Owner / domain | Owner-native truth | Host admissible role | Forbidden collapse |
| --- | --- | --- | --- |
| Harness | Agent/Run/context/invocation/control mediation and Harness-native result/receipt semantics | retain/refer to bounded continuity and foreign-run references; support external handoff | Host does not own Agent cognition, Run truth, Tool-step semantics, or global completion |
| Runtime | Workspace/Job/Attempt/operation/realization, physical execution/effect evidence and reconciliation within Runtime | retain/refer to exact Runtime identities and bounded observations | Host does not proxy Runtime or reinterpret physical success as semantic Task completion |
| Ordivon Normative / relevant constitutive order | context-relative constitutive/normative admission, consequence, transformation, validity/standing | reference order-native facts/evidence | HDF43 `Valid_O(F)` is not Host-owned validity |
| World | external provider/resource/entity/message/currentness semantics | opaque retained owner namespace, revision/digest pointers, bounded inspection | Host witness history is not World current truth |
| Finance and domain owners | market/account/order/domain semantics | task-private continuity and exact owner references where needed | Host does not own domain truth or domain action semantics |
| Human / relevant social order | attention, consent, commitment, responsibility, constituted roles | record explicit continuity claims/references only when supplied | continuity, silence, or tool use does not manufacture consent/authority |
| Network | connectivity/transport/replication mechanism truth | consume/refer to Network facts when a continuity case needs them | Host is not transport, consensus, or federation substrate |

## Bridge law

A durable foreign reference does not transfer foreign ownership.

A Host checkpoint is a bounded semantic-working claim sufficient for Host continuity. Owner-current facts inside or behind that checkpoint must still be revalidated with the source owner when currentness matters.
